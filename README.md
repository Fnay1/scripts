## ✍️ Как добавлять скрипт

1. Положи файл в подходящую папку (`recon/`, `utils/` и т.д.).
2. В начало файла добавь **шапку-описание** (см. шаблон ниже).
3. Добавь строку в таблицу «Каталог скриптов» выше.

### Шаблон шапки

**Python:**
```python
#!/usr/bin/env python3
"""
Название : subdomain_probe.py
Что делает: перебирает поддомены и проверяет живые хосты
Зачем    : быстрый первичный recon перед пентестом
Автор    : Fnay
Пример   : python3 subdomain_probe.py -d target.com
"""
```

**Bash:**
```bash
#!/usr/bin/env bash
# Название : portscan.sh
# Что делает: быстрый скан топ-портов через nmap
# Зачем    : ускорить старт разведки
# Пример   : ./portscan.sh 10.10.10.10
```

> ⚠️ Скрипты предназначены для легального пентеста, обучения и CTF. Применение без разрешения владельца системы незаконно.
