# winPEAS — Windows Privilege Escalation Awesome Script

Инструмент для автоматического поиска путей **повышения привилегий в Windows**
(до `Administrator` / `NT AUTHORITY\SYSTEM`). Запускается на цели после получения
доступа с ограниченными правами и подсвечивает опасные находки цветом.

- Часть проекта PEASS-ng: <https://github.com/peass-ng/PEASS-ng>

## Зачем

Windows-эскалация опирается на множество мелочей: права служб, реестр, задачи,
токены, AlwaysInstallElevated, сохранённые креды и т.п. winPEAS собирает всё это
за один прогон и выделяет самое перспективное, экономя время.

## Что проверяет (основное)

- **Службы**: незакавыченные пути (unquoted service path), права на изменение
  службы/бинарника/реестра, слабые ACL.
- **Реестр**: `AlwaysInstallElevated`, автозапуск, сохранённые пароли (autologon, PuTTY, VNC, SNMP).
- **Токены и привилегии**: `SeImpersonate`/`SeAssign` (векторы Potato), группы пользователя.
- **UAC**, политики, patch level, известные CVE и отсутствующие обновления.
- **Задачи планировщика**, папки с правом записи в `%PATH%` (DLL hijacking / path).
- **Креды**: файлы конфигов, `unattend.xml`, WiFi-профили, браузеры, DPAPI, история.
- **Сеть, шары, установленное ПО** с известными уязвимостями.

## Цветовая маркировка

- 🔴 **Красный** — потенциальный вектор эскалации (смотреть первым).
- 🟢 Зелёный — обычно безопасно/информационно.
  (Если цвета не видны в старой консоли — включите: `reg add HKCU\Console /v VirtualTerminalLevel /t REG_DWORD /d 1`.)

## Где применимо

Пост-эксплуатация в пентесте/CTF после получения shell на Windows-хосте; аудит
собственной рабочей станции/сервера на мисконфигурации.

## Как запускать

```powershell
# Полный прогон (выбрать разрядность цели):
.\winPEASx64.exe                 # 64-бит
.\winPEASany.exe                 # универсальная сборка (.NET Any CPU)

# С логом в файл:
.\winPEASx64.exe log             # создаст out.txt

# Быстрее/точечно:
.\winPEASx64.exe systeminfo userinfo servicesinfo    # только выбранные модули
.\winPEASx64.exe quiet cmd fast                       # тихо, только cmd-проверки, быстро

# Без .NET на цели — batch-версия (беднее, но работает почти везде):
winPEAS.bat
```

Модули (примеры): `systeminfo`, `userinfo`, `servicesinfo`, `applicationsinfo`,
`networkinfo`, `windowscreds`, `browserinfo`, `filesinfo`. Аргумент `help` —
полный список.

## Файлы в папке

| Файл | Когда использовать |
|------|--------------------|
| `winPEAS.bat` | Fallback без .NET — беднее по возможностям, но запускается почти везде |
| `download-exe.sh` | Скачать `.exe`-версии из официального релиза (см. ниже) |

### Почему `.exe` не лежат в репозитории

`.exe`-сборки winPEAS **не хранятся здесь**: GitHub push-protection блокирует их,
т.к. внутри зашиты сигнатуры для поиска чужих секретов, а secret-scanning
принимает их за настоящие ключи (ложное срабатывание). Скачайте бинарники по
требованию:

```bash
bash download-exe.sh
# создаст winPEASx64.exe (64-бит), winPEASany.exe (универсальная), winPEASx86.exe
```

> ⚠️ `.exe`-версии часто ловятся антивирусом (ожидаемо для pentest-инструмента).
> В релизах проекта есть «obfuscated» сборки (`*_ofs.exe`) и `.bat` как запасной
> вариант. Загружайте на цель только на авторизованных стендах.
