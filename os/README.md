# os — повышение привилегий (Privilege Escalation Enumeration)

Инструменты для **пост-эксплуатации**: после получения первичного доступа к
системе (пользователь с низкими правами) они автоматически собирают всё, что
может помочь **поднять привилегии до root / SYSTEM** — мисконфигурации, слабые
права, креды в файлах, уязвимые сервисы, известные CVE ядра и т.д.

Здесь размещён набор **PEASS-ng** (Privilege Escalation Awesome Scripts SUITE,
next generation) — де-факто стандарт для этой задачи:

| Папка | Инструмент | ОС | Формат |
|-------|-----------|-----|--------|
| [`linpeas/`](linpeas) | **linPEAS** | Linux / Unix / macOS | shell-скрипт `.sh` |
| [`winpeas/`](winpeas) | **winPEAS** | Windows | `.exe` (.NET) и `.bat` |

- Официальный репозиторий: <https://github.com/peass-ng/PEASS-ng>
- Версия релиза в этой папке: **`20260715`** (актуализировать — см. ниже).
- Лицензия проекта: MIT (принадлежит авторам PEASS-ng, не мне).

## Зачем это нужно

Ручной поиск путей эскалации (проверка sudo, SUID, cron, capabilities, служб,
токенов, реестра, паролей в конфигах…) занимает много времени и легко упустить
деталь. PEASS автоматизирует эту рутину и **подсвечивает цветом** самые
интересные находки (красный/жёлтый = высокий шанс эскалации), экономя часы.

## Где применимо

- Пентест/CTF **после** получения shell на целевой машине.
- Аудит собственных серверов на мисконфигурации до того, как их найдёт злоумышленник.

> ⚠️ **Только для авторизованного использования.** Запуск на чужих системах без
> разрешения владельца незаконен. Это диагностический инструмент, не эксплойт —
> он **читает** состояние системы, но выхлоп содержит чувствительные данные
> (хеши, ключи, пути) — обращайтесь с отчётами аккуратно.

## Как обновить до последней версии

```bash
BASE="https://github.com/peass-ng/PEASS-ng/releases/latest/download"
curl -L "$BASE/linpeas.sh"     -o linpeas/linpeas.sh
curl -L "$BASE/winPEAS.bat"    -o winpeas/winPEAS.bat
curl -L "$BASE/winPEASany.exe" -o winpeas/winPEASany.exe
curl -L "$BASE/winPEASx64.exe" -o winpeas/winPEASx64.exe
```

Подробности по каждому инструменту — в README внутри папок.
